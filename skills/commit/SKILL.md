# Commit

Commit the completed phase as one atomic commit. Write a short commit title and description in plain language explaining what changed and why. Put both in the commit message itself, not only in the chat.

Inspect the diff and include only changes from this phase. Preserve unrelated staged and unstaged work. If the phase cannot be identified from the conversation and diff, ask before committing.

Follow the repository's commit conventions. Do not push unless asked. Briefly report the commit hash and title when done.
